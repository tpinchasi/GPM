GPU Cloud Workplan

Move simulator generation and the per-turn labeling pipeline off the local M4 Pro onto a rented NVIDIA GPU, without losing Langfuse traces when a spot machine goes away.

Written 2026-09-15 Nothing provisioned yet Prices verified 2026-09-15 Tick boxes save in this browser
Key finding

Idle time costs more than the hourly rate.

A full 834-session run costs between $0.23 and $10.90 of GPU time. The same GPU left running for a month costs $245 to $780. Spot saves 60 to 70 percent of a number that is already small. Forgetting to stop the box wastes far more.

Cost controls, highest impact first:

  1. Automatic stop when idle
  2. Right-sizing the model to the job
  3. Throughput from continuous batching
  4. Spot or community pricing
Verified in the current source

Already working in our favour

Three properties of the existing code make this migration cheaper than it looks.

Generation resumes after every sessiongenerate_sessions.py · run_batched_generation.py

Already spot-ready. A reclaim costs at most one in-flight session. Only the checkpoint file's location has to change.

Langfuse is not the system of recordexport_langfuse_conversations.py · new_export2/ · export_20260914/

Traces are exported to JSON after each run. Losing the Langfuse database is annoying, not fatal, which lowers the persistence bar.

The inference endpoint is one variableOLLAMA_URL · agents/model_config.py

Phase 2 is a configuration change, not a code change.

Because the exports are the durable copy, Langfuse retention becomes a real deadline. Cloud Hobby keeps 30 days and Core keeps 90. Export must run inside that window.

Settle before spending

Four decisions

Each has a recommendation and the condition that would change it.

D1 · Drives every cost figure

Which model is production?

Small models narrate fake confirmations on the closing turn. qwen3.8:27b closed the loop reliably in the 2026-09-12 runs. Decide from Phase 3 measurements, not argument.

ProductionVRAMCard
7B + e4b24 GBRTX 4090 · $0.34/hr
27B class48 GBL40S · $1.09/hr

If the small model's miss rate is acceptable for generation, take the 4090 and save three times over.

D2

Langfuse, managed or self-hosted?

Cloud Core at $29 a month. One full cycle is about 50,000 units. Hobby caps at 50,000 and then stops tracing without warning.

Self-hosting wins past roughly four full cycles a month, because unit pricing punishes bulk synthetic runs.

D3

Which provider?

RunPod. Network volumes, per-second billing, and the cheapest verified 4090 rate. Pin the region first, because volumes are region-locked.

Choose AWS g5.xlarge spot at $0.44/hr in us-east-1 if one account with IAM and budget alarms matters more.

D4

Ollama or vLLM?

Ollama first. It needs no code change. vLLM gives 5 to 15 times the throughput but needs per-model tool-call parsers, and we depend on 41 action tools.

Revisit once Phases 1 to 4 are stable. Never couple the migration to that risk.

Parity gate

0 / 5 doneThe phase most likely to be skipped, and the most expensive to skip.

Apple MLX builds and CUDA GGUF builds produce different outputs. The labeling pipeline's calibration and accuracy baselines were set against the old ones.

Exit
A written parity verdict: outputs are equivalent, differences are understood and accepted, or back to Phase 2 with another tag.
4

Auto-stop, then spot

0 / 5 doneThe watchdog first. It is worth more than the spot discount.
Exit
A forced kill costs at most one in-flight session, and an idle node stops itself.
Accepted
A hard kill skips the Langfuse flush, so traces buffered at that moment are lost. The checkpoint log is the resume source of truth, so no work is lost.

Open questions

  • Is the 27B model needed on every turn, or only on closing turns? Splitting would close most of the cost gap, but it is a design change.
  • Is the small models' closing-turn miss rate a defect or a behavioural signal worth keeping? The answer changes what parity means in Phase 3.
  • At what run cadence does self-hosted Langfuse beat Cloud Core? Recompute once real unit counts arrive.

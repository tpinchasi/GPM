# vLLM's locked sets (D158)

One JSON file per vLLM version, Python minor version and processor, generated by GPM's release
(`tools/vllm-lock`) — never edited by hand. The agent installs vLLM only from these.

Each holds `vllm`, `python`, `platform`, `driver_floor`, `glibc`, `size_bytes` (the wheels'
sum), `requirements` — every pin with the sha256 of the one wheel pip takes there — and, for the
reader, `cuda_runtime` and `wheels`. See docs/release-checklist.md, "Every release".
